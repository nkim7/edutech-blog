01

Convolution

Convolution is a sliding calculation. A small window of weights moves across a grid, multiplies each weight by the number underneath it, adds the products, and writes one output value. Step through the animation to see that calculation happen one position at a time.

Convention — convolution vs. cross-correlation: Most image-processing libraries implement cross-correlation but still call it convolution. This demo follows that common convention; for symmetric kernels like blur, flipping the kernel would not change the result.

01

Window size

How many input values contribute to each output value. A 2×2 window uses 4 values at a time; a 3×3 window uses 9.

02

Stride

How many positions the window jumps each step. Stride 1 visits neighbouring positions; stride 2 skips one position each time.

03

Padding

The window cannot extend beyond the grid unless extra values are added around the border.

None (valid): only calculate positions where the full window fits. A 2×2 window on a 3×3 input produces a 2×2 output.

Zero-pad (same): add 0s around the input so the window can visit the original edge positions. With stride 1, the output keeps the input size. For even-sized kernels (e.g. 2×2) padding is asymmetric because there is no single center pixel — in this demo the extra padded cells appear on the bottom and right.

The sliding calculation is the same for every spatial filter. What changes is the pattern of weights — and different patterns reveal entirely different features of the image.

Spatial Filters

Each filter is a deliberate choice of weights in a convolution kernel. Different patterns ask different questions about the pixel neighbourhood — and this section shows what each pattern reveals.

Canny uses two of these filters in sequence: first, a Gaussian filter smooths the image; then, Sobel filters estimate horizontal and vertical intensity changes. The other filters are included for exploration.

Kernel pattern reference

In image processing, a filter is just a convolution with a particular kernel. The pattern of weights is a mathematical "question" asked at every pixel neighbourhood.

Σw = 1, all positive → each output is a weighted average of its neighbours → blurs the image
Σw = 0, mixed signs → constant regions cancel to zero; changes produce a large response → detects edges
large centre − neighbours → amplifies the difference between a pixel and its surroundings → sharpens
Σw = 1, asymmetric mixed signs → directional signs plus an offset create a relief effect → emboss (a visual effect, not a pure derivative edge detector)

Gaussian blur and Sobel reveal where image intensity changes. But a raw gradient often produces a thick ridge of responses across an edge. Before assembling the full Canny pipeline, learn how Non-Maximum Suppression keeps only the local maximum across each gradient ridge — thinning it to a single-pixel line.

03

Non-Maximum Suppression

After Sobel, a single physical edge can light up several neighbouring pixels, producing a thick gradient ridge. Non-Maximum Suppression (NMS) makes that ridge thinner: for every candidate pixel, compare its gradient magnitude with two samples taken along the gradient direction. Keep the candidate only if it is a local maximum.

General rule
NMS(p) = M(p)  if M(p) ≥ M(p − ĝ) and M(p) ≥ M(p + ĝ)  ;  otherwise 0

M is gradient magnitude. ĝ = [cosθ, sinθ] is one unit step along the gradient direction, where θ = atan2(Gy, Gx). The gradient points perpendicular to the edge, so NMS compares across the edge's width.

For a non-axis-aligned gradient, samples at (x ± cosθ, y ± sinθ) can fall between grid pixels. Bilinear interpolation estimates their magnitudes.

04

Double Thresholding

After NMS, each remaining edge pixel has a gradient strength. Double thresholding does not detect new edges — it classifies these already-thinned candidates by strength. Low responses are discarded, middle responses are kept temporarily as weak edges, and high responses are kept as strong edges. Hysteresis then decides which weak edges survive.

Hyperparameter Tuning

Run through the same five Canny stages again, this time with editable parameters. Change a value at any step and see how it propagates through every stage after it. Different images call for different values — fine-textured subjects need gentler blur, while high-contrast scenes can handle more aggressive thresholds.

Quick parameter guide
σ — blur strength before gradientshigher σ → smoother image, less noise, fewer fine details
Thi — strong-edge cutoffhigher Thi → fewer confirmed strong edges
Tlo — weak-edge floorhigher Tlo → fewer weak candidates

Constraint: Tlo must stay below Thi. Thresholds are percentages of the peak gradient magnitude.

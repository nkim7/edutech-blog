00

What is convolution?

An image is a 2D grid of numbers. Convolution slides a small matrix — the kernel — across every position, replacing each pixel with a weighted sum of its neighbourhood. The kernel's weights decide what structure is detected.

01

Window size

How many neighbours contribute to each output pixel. A 3×3 kernel looks 1 pixel in every direction; a 5×5 looks 2. Larger = broader patterns, more compute, potential blur of fine details.

02

Stride

How many pixels the kernel jumps each step. Stride 1 = dense, overlapping. Stride 2 = the output shrinks by ~half. Large strides downsample — common in CNN pooling layers.

03

Padding

The kernel needs space to centre on every pixel. Edge pixels have no neighbours outside the image — what happens there?

None (valid): skip edge pixels entirely. A 3×3 kernel on a 5×5 image can only centre on the inner 3×3 region → output shrinks to 3×3.

Zero-pad (same): surround the input with a border of 0s first, giving the kernel room to centre on every original pixel → output stays 5×5.

01

Spatial filters

Every filter is just a choice of weights in a convolution kernel. The operation is always the same weighted sliding sum — only the numbers change. Each set of numbers asks a different question about the neighbourhood.

(I ★ k)[x, y] = Σi=−nn Σj=−nn I[x+i, y+j] · k[i, j]
I — input image, 2D array of pixel values (0–255)
k — kernel matrix, defines what is detected
x, y — position of the output pixel being computed
n — half the kernel size (n=1 for 3×3, n=2 for 5×5)

σ — Gaussian blur radius

Larger σ = wider smoothing kernel = noise suppressed more aggressively. But fine edges merge. σ=0 skips blur entirely — watch what happens.

G_σ(x,y) = (1/2πσ²)·exp(−(x²+y²)/2σ²) kernel radius r = ⌈3σ⌉

Thi (% of max gradient): strong-edge floor. Tlo as % of Thi: weak-edge floor. Hysteresis: weak pixels survive only if 8-connected to a strong pixel.

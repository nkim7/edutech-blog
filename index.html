01

Convolution

Convolution is a sliding calculation. A small window of weights moves across a grid, multiplies each weight by the number underneath it, adds the products, and writes one output value. Step through the animation to see that calculation happen one position at a time.

01

Window size

How many input values contribute to each output value. A 2×2 window uses 4 values at a time; a 3×3 window uses 9.

02

Stride

How many positions the window jumps each step. Stride 1 visits neighbouring positions; stride 2 skips one position each time.

03

Padding

The window cannot extend beyond the grid unless extra values are added around the border.

None (valid): only calculate positions where the full window fits. A 2×2 window on a 3×3 input produces a 2×2 output.

Zero-pad (same): add 0s around the input so the window can visit the original edge positions. With stride 1, the output keeps the input size.

A note on terminology: in image processing and most libraries, "convolution" conventionally means cross-correlation — the kernel slides without being flipped 180°. For symmetric kernels (Gaussian, Laplacian, Identity) the two operations produce identical results. For asymmetric kernels like Sobel and Emboss, which appear in the next section, this unflipped convention is the standard.

The sliding calculation is the same for every spatial filter. What changes is the pattern of weights — and different patterns reveal entirely different features of the image.

02

Spatial Filters

Now that the convolution operation is clear, introduce filters: each filter is a deliberate choice of weights in a convolution kernel. The sliding calculation stays the same, but different weights ask different questions about the neighbourhood.

In image processing, a filter is just a convolution with a particular kernel. The pattern of weights is a mathematical "question" asked at every pixel neighbourhood. Three patterns cover nearly all classical filters:

Σw = 1, all positive → each output is a weighted average of its neighbours → blurs the image
Σw = 0, mixed signs → constant regions cancel to zero; changes produce a large response → detects edges
large centre − neighbours → amplifies the difference between a pixel and its surroundings → sharpens

Canny uses two of these filters in sequence: first, a Gaussian filter smooths the image; then, Sobel filters estimate horizontal and vertical intensity changes. The other filters are included for exploration, so users can also try Laplacian, Sharpen, Emboss, and Identity to see how each one transforms the same drawing.

03

Non-Maximum Suppression

After Sobel, a single physical edge can light up several neighbouring pixels, producing a thick gradient ridge. Non-Maximum Suppression (NMS) makes that ridge thinner: for every candidate pixel, compare its gradient magnitude with two samples taken along the gradient direction. Keep the candidate only if it is a local maximum.

General rule
NMS(p) = M(p)  if M(p) ≥ M(p − ĝ) and M(p) ≥ M(p + ĝ)  ;  otherwise 0

M is gradient magnitude. ĝ is one unit step along the gradient direction. The gradient always points perpendicular to the edge — toward the direction of maximum intensity change — so NMS compares across the edge's width, not along it. When ĝ falls between pixels, this demo interpolates the two comparison samples.

04

Double Thresholding

After NMS, each remaining edge pixel has a gradient strength. Double thresholding sorts those pixels into three groups: strong edges, weak edges, and discarded responses.

Double thresholding does not detect new edges. It only classifies the already-thinned NMS candidate pixels by strength: low responses are discarded, middle responses are kept temporarily as weak edges, and high responses are kept as strong edges. In the next step, hysteresis keeps weak edges only if they connect to strong edges.

Next — Edge Tracking by Hysteresis. The classification above feeds directly into the final stage. Hysteresis keeps every strong-edge pixel unconditionally, then traces outward from each strong pixel and recovers adjacent weak-edge pixels that touch it. A weak pixel survives only when it connects — directly or through a chain of other weak pixels — to a strong anchor. Isolated weak responses with no strong connection are discarded.

Hyperparameter Tuning

Run through the same five Canny stages again, this time with editable parameters. Change a value at any step and compare how it changes that stage and every stage after it.

Parameter reference

σ — Gaussian Blur Radius: smooths the image before edge detection. A low value preserves fine detail; a high value suppresses noise but can merge nearby edges.

Thi — Strong Edge Threshold: sets the minimum gradient strength for a definite edge. Too high and real edges disappear; too low and noise becomes an edge.

Tlo — Hysteresis Ratio: sets the weak-edge floor as a fraction of Thi. Weak pixels survive only when they connect to a strong edge.

What are hyperparameters?

Before you tune, understand what you are tuning.

A hyperparameter is a value you set before running an algorithm — it controls how the algorithm behaves, but is not learned from the data itself. Hyperparameter tuning is the process of finding the values that produce the best result for your specific image or task.

In Canny edge detection, three hyperparameters shape everything:
